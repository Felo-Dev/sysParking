Sistema de parqueo
Registrar Nuevo Cliente

Registrar Nuevo Cliente permite agregar un cliente al sistema de parqueo, ingresando su nombre, placa del vehículo, y fecha de inicio.

Registrar una nueva tarifa

Registra una nueva tarifa ingresando el tipo de vehículo, tiempo de uso y costo.

Registrar un vehículo

Registra un vehículo ingresando la placa, tipo y datos del cliente.
